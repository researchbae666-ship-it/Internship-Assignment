# RefillLoop Task 3 campaign research

RefillLoop is a fictional proposed modular reusable-hydration concept. Every
feature, price, persona, budget, target, and performance value in this task is
an assumption or planning target, not an existing-product claim or achieved
result.

Run `python digital_marketing/research/task3/build_campaign.py` to create the
machine-readable calendar. It validates 30-day coverage, the three required
platforms, required action fields, and budget arithmetic before writing JSON.

The campaign uses a planned cadence of one Instagram action each day, LinkedIn
on twelve selected professional-context days, and seven YouTube Shorts plus
four long-form videos. This provides a daily editorial rhythm without forcing
the same posting frequency on every platform.
