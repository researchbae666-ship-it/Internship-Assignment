# Research observation template

Use one completed record per source or post during an approved task-research
phase. Do not populate a field from memory or inference.

```text
Observation ID:
Task / question:
Brand or website:
Source URL:
Collected (UTC):
Publicly visible publication date (if any):
Observation window:
Access method:
Observable facts (quoted or transcribed carefully):
Unavailable fields / access limits:
Calculation (formula, inputs, and units):
Classification: observed fact | transparent estimate | assumption | proposal
Reviewer notes:
```

For competitor engagement, use comparable posts within one stated window. Show
each input. When only likes and comments are publicly visible,
`(visible likes + visible comments) / visible followers * 100` is an
**estimated visible engagement rate**, not platform analytics. If the
denominator or a comparable interaction field is absent, report the rate as
unavailable.
